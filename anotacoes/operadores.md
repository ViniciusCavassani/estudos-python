# Operadores e precedência

Resumo dos operadores praticados nos exercícios.

| Operador | Uso |
|---|---|
| `+` | Adição |
| `-` | Subtração |
| `*` | Multiplicação |
| `/` | Divisão com resultado real |
| `//` | Divisão inteira, descartando a parte decimal do quociente |
| `%` | Resto da divisão |
| `**` | Potência |
| `==` | Comparação de igualdade |

## Ordem geral de precedência

1. Parênteses: `()`
2. Potência: `**`
3. Multiplicação, divisões e resto: `*`, `/`, `//`, `%`
4. Adição e subtração: `+`, `-`

Parênteses podem deixar a ordem desejada explícita. A formatação com `str.format()` também aparece nos exercícios para inserir valores em mensagens e controlar casas decimais.
